## 📌 Features

- 📱 **Multi-Device Support**: Connects seamlessly using QR Code or Pairing Code.
- ⚡ **Automated Status Handling**: Auto-read, auto-type, and presence status management.
- 🛠️ **Modular Command System**: Easily extensible plugins and handlers.
- 🔄 **Auto-Reconnection**: Automatically attempts reconnects if the connection drops.
